<h1 align="center">Food Order API</h1>

Esta é uma API simples para gerenciar pedidos de comida, desenvolvida com Express.js. A API permite criar, listar, atualizar, deletar e alterar o status dos pedidos de comida.

<h2 align="center">Funcionalidades</h2>

+ Criar Pedido: Adiciona um novo pedido com detalhes do cliente, pedido e preço.

+ Listar Pedidos: Obtém uma lista de todos os pedidos cadastrados.

+ Atualizar Pedido: Atualiza as informações de um pedido existente.

+ Deletar Pedido: Remove um pedido específico.

+ Buscar Pedido por ID: Retorna os detalhes de um pedido específico.

+ Atualizar Status do Pedido: Altera o status de um pedido para "Pronto".

<h2 align="center">Funcionalidades</h2>

+ Node.js: Ambiente de execução para JavaScript.
+ Express.js: Framework para criação de aplicações web e APIs.
+ UUID: Biblioteca para gerar identificadores únicos para os pedidos.
+ CORS: Middleware para permitir requisições de diferentes origens.
